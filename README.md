# Meu Portfólio Acadêmico 

Este é um projeto de desenvolvimento web criado como atividade avaliativa para a cadeira de Programação 4 do curso de Sistemas de Informação da Universidade de Pernambuco (UPE).

## Sobre o Projeto
O objetivo deste projeto foi construir um portfólio pessoal responsivo e interativo, aplicando os conceitos fundamentais de desenvolvimento web aprendidos em aula. O site apresenta minhas informações, habilidades acadêmicas (Java, Python, SQL) e um formulário de contato funcional.

## Funcionalidades e Requisitos Cumpridos
* **Responsividade (Mobile-First):** Layout adaptável para celulares e computadores utilizando o sistema de Grid do Bootstrap.
* **Menu Interativo:** Barra de navegação com botão "hambúrguer" funcional em telas menores.
* **Validação de Formulário:** Uso de JavaScript para impedir o envio de mensagens vazias, exibindo alertas coloridos na tela.
* **Interação Extra:** Contador de caracteres em tempo real na caixa de mensagem, com mudança de cor ao se aproximar do limite.

## 🛠️ Tecnologias Utilizadas

* **CSS3** 
* **JavaScript**
